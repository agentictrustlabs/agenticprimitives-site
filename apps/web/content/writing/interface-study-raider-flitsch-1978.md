## The study and why we depend on it

**S. I. Raider and R. Flitsch, “X-Ray Photoelectron Spectroscopy of SiO2-Si Interfacial Regions: Ultrathin Oxide Films”, IBM J. Res. Develop. 22(3), 294-303 (1978), doi:10.1147/rd.223.0294.**

This is the challenge's composition-profile target for planar silicon (system 1): the only paper in the library that measures how wide the silicon-to-oxide transition is and how it changes with processing. The library had it as skimmed, with no dataset and no stored recipe. The predictor reports “composition profile” as not modelled for every planar-silicon history. This page writes the paper's sample groups as histories, sets the printed widths and compositions beside them (the rows say “no program”), scores the one number a program does report (the thinnest oxide at 850 °C), and compares the printed values with an unvalidated candidate model of the silicon-to-oxide gradient that another session is building.

## How well can this study be reproduced?

**Low.** The paper's result is one transition-region width and composition per orientation, fitted to a cloud of films (Figure 5) grown at 23 to 850 °C in six oxidants, with and without an anneal. No film has its own recipe: temperatures between 100 and 700 °C are given only as a range, the 850 °C and room-temperature times are not given, the O2/N2 ratio is not given, and which films were annealed is not said. The result is stated to be independent of all of these, so the missing recipes matter less for the width than they would for a growth rate, but no single film can be followed from history to number.

#### Timing the paper does not give

- Duration of the 1050 °C sacrificial oxidation (set by its 200 nm target), the HF etch, the rinse and drying, and the time before reoxidation.
- Room-temperature oxidation in air or water: duration not stated (the paper refers to its ref. 18).
- 100-700 °C in dry O2: “generally for about half an hour”, varied in some cases; the temperature of each film is not given.
- (111) at 600 °C and every 850 °C oxidation: no time stated; only the 1.1 nm minimum thickness at 850 °C.
- N2 anneal: 10 to 30 min, and which films had it, not stated.
- No heat-up, push, pull or cooling stated for any heated film.
- Time in air between oxidation, ellipsometry and XPS: “rapidly” for ellipsometry; not stated for XPS.

### What the second reading changed

- The project had no dataset, no stored recipe and no transcription for this paper; the library marks it “skimmed”. Every number on this page is from the second reading.
- SOURCE.md and the library note say the region “depends on orientation, not on other process parameters”, which is the paper's summary. The second reading adds what that rests on: one fitted width per orientation in 0.25 nm steps, from a cloud of films whose recipes are not individually given.
- SOURCE.md calls it a candidate for system 1's composition target. The paper prints no Si+1/Si+2/Si+3 fractions and says its spectra cannot be resolved into suboxide lines, so the comparable quantities are width, first-layer composition and Si-Si bond count, not suboxide fractions.

| transition region width (0.25 nm layers, linear gradation) | `(none)` | a fitted parameter of the paper's XPS layer model | Not the same quantity as a 10-90% width of a continuous profile: the paper's width is the full extent of non-stoichiometric layers, in 0.25 nm steps. |
| SiOx average composition of a layer, x from δ = 2.2x eV | `O/Si (the gradient model's oxygen_per_silicon)` | composition | δ is the Si(2p) oxide shift referred to the substrate line at 99.3 eV. |

The model itself, `experiments/si_oxide_gradient/reaction_diffusion.isl.template`, as it is written. Every equation the simulation uses is in this text; the runtime holds no physics.

```isl
# Exploratory Si -> SiOx -> SiO2 composition gradient on a fixed one-dimensional slab.
# All transport and reaction coefficients below are HYPOTHESES, not fitted or computed.
# Motivation for resolving Si(0)...Si(IV): Himpsel et al., PRB 38, 6084 (1988),
# doi:10.1103/PhysRevB.38.6084. That paper does not supply these kinetic coefficients.
#
# S0...S4 are fractions of silicon sites in each formal oxidation state.
# M is mobile O2 molecules per silicon site; B is bound oxygen in O2 equivalents
# per silicon site. Each oxidation-state increment binds 1/4 O2 per Si, assuming
# bridging oxygen. Thus O/Si = (S1 + 2 S2 + 3 S3 + 4 S4)/2 = 2 B.
# B is a redundant oxygen ledger, checked against the oxidation-state fields.
# Gas_ledger + integral(M) + integral(B) is conserved; negative Gas_ledger means
# oxygen entered from the atmosphere. Silicon sites are conserved separately.
# The coordinate is fixed: volume expansion, strain, orientation, charge states,
# reverse reactions, hydrogen chemistry and atomistic structure are not represented.
SAMPLE Gradient {{ FAMILY: Si_Planar }}
GRID z {{ UNIT: cm; FROM: 0; TO: {length_cm}; CELLS: {cells} }}
FIELD S0 {{ UNIT: 1; GRID: z; INITIAL: {initial_si}; MIN: 0; MAX: 1 }}
FIELD S1 {{ UNIT: 1; GRID: z; INITIAL: 0; MIN: 0; MAX: 1 }}
FIELD S2 {{ UNIT: 1; GRID: z; INITIAL: 0; MIN: 0; MAX: 1 }}
FIELD S3 {{ UNIT: 1; GRID: z; INITIAL: 0; MIN: 0; MAX: 1 }}
FIELD S4 {{ UNIT: 1; GRID: z; INITIAL: {initial_oxide}; MIN: 0; MAX: 1 }}
FIELD M {{ UNIT: 1; GRID: z; INITIAL: 0; MIN: 0; MAX: 1 }}
FIELD B {{ UNIT: 1; GRID: z; INITIAL: {initial_oxide}; MIN: 0; MAX: 1 }}
STATE Gas_ledger {{ UNIT: cm; INITIAL: 0; MIN: -1; MAX: 1 }}
CONTROL T {{ UNIT: K }}
CONTROL p_O2 {{ UNIT: atm }}
PARAMETER k_B {{ VALUE: 8.617333262e-5; UNIT: eV K^-1; STATUS: constant }}
PARAMETER T_ref {{ VALUE: 1273.15; UNIT: K; STATUS: constant }}
PARAMETER p_ref {{ VALUE: 1; UNIT: atm; STATUS: constant }}
PARAMETER initial_front {{ VALUE: {initial_front_cm}; UNIT: cm; STATUS: hypothesis }}
PARAMETER seed_width {{ VALUE: 1.0e-12; UNIT: cm; STATUS: hypothesis }}
PARAMETER D_si {{ VALUE: 1.0e-14; UNIT: cm^2 s^-1; STATUS: hypothesis }}
PARAMETER D_oxide {{ VALUE: 1.0e-11; UNIT: cm^2 s^-1; STATUS: hypothesis }}
PARAMETER E_D {{ VALUE: 1.2; UNIT: eV; STATUS: hypothesis }}
PARAMETER k0 {{ VALUE: 80; UNIT: s^-1; STATUS: hypothesis }}
PARAMETER k1 {{ VALUE: 60; UNIT: s^-1; STATUS: hypothesis }}
PARAMETER k2 {{ VALUE: 40; UNIT: s^-1; STATUS: hypothesis }}
PARAMETER k3 {{ VALUE: 20; UNIT: s^-1; STATUS: hypothesis }}
PARAMETER E_reaction {{ VALUE: 1.2; UNIT: eV; STATUS: hypothesis }}
PARAMETER surface_speed {{ VALUE: 1.0e-3; UNIT: cm s^-1; STATUS: hypothesis }}
PARAMETER mobile_at_1atm {{ VALUE: 1.0e-5; UNIT: 1; STATUS: hypothesis }}
PARAMETER N_sites {{ VALUE: 5.0e22; UNIT: cm^-3; STATUS: hypothesis }}
QUANTITY thermal_D {{ UNIT: 1; EQUATION: thermal_D = exp(E_D / k_B * (1 / T_ref - 1 / T)) }}
QUANTITY thermal_k {{ UNIT: 1; EQUATION: thermal_k = exp(E_reaction / k_B * (1 / T_ref - 1 / T)) }}
QUANTITY gas_flux {{ UNIT: cm s^-1; EQUATION: gas_flux = surface_speed * (mobile_at_1atm * p_O2 / p_ref - left(M)) }}
CONTROL_TRAJECTORY History {{
{runs}
}}
OPERATOR OxygenTransport : Transport {{
    FLUX: J(M) = -(D_si + (D_oxide - D_si) * S4) * thermal_D * grad(M)
    BOUNDARY: M AT left FLUX = gas_flux
    EQUATION: d(Gas_ledger)/dt = -gas_flux
    CONSERVATION: Gas_ledger + integral(M) = const
}}
# These sequential steps are a coarse-grained kinetic hypothesis, not elementary
# reactions or charges measured on individual atoms.
OPERATOR SequentialOxidation : OxideGrowth {{
    EQUATION: d(S0)/dt = -thermal_k * k0 * M * S0
    EQUATION: d(S1)/dt = thermal_k * M * (k0 * S0 - k1 * S1)
    EQUATION: d(S2)/dt = thermal_k * M * (k1 * S1 - k2 * S2)
    EQUATION: d(S3)/dt = thermal_k * M * (k2 * S2 - k3 * S3)
    EQUATION: d(S4)/dt = thermal_k * k3 * M * S3
    EQUATION: d(B)/dt = 0.25 * thermal_k * M * (k0 * S0 + k1 * S1 + k2 * S2 + k3 * S3)
    EQUATION: d(M)/dt = -0.25 * thermal_k * M * (k0 * S0 + k1 * S1 + k2 * S2 + k3 * S3)
    CONSERVATION: integral(S0) + integral(S1) + integral(S2) + integral(S3) + integral(S4) = const
    CONSERVATION: integral(M) + integral(B) = const
}}
```

**With its own parameters the model does not match.** It barely oxidizes: 0.0065 nm of SiO2-equivalent in 10 min at 850 °C from a bare surface, where the paper's films are at least 1.1 nm. Its oxygen dissolves deep into the silicon instead of reacting at a front, so 98% of its suboxide is Si+1 spread thinly over nanometres, with 1.9 × 10^14 Si-Si bonds cm⁻² against 0.8 × 10^15. Started from its default sharp 1.0 nm oxide, its 10-90% width is the grid spacing (0.02 nm). It does nothing at 23 to 300 °C, and it gives (111) exactly what it gives (100).

**What its parameters would need to be (found by hand, not fitted into the model).** Reaction rates about 100 times faster (k0 to k2 of 4000 to 8000 s⁻¹), a surface oxygen solubility 1000 times higher (1e-2 per site) with oxide diffusivity 1000 times lower (1e-14 cm²/s at 1000 °C), and a last step Si(III) → Si(IV) about 100 times slower than the others (k3 = 40 s⁻¹, against the template's 20 with k2 = 40). With those (the “(100) set”) it grows 0.5 nm in 1 min and 1.7 nm in 10 min at 850 °C, makes 8.1 × 10^14 Si-Si bonds cm⁻² (the paper's (100) value is 0.8 × 10^15), puts 82% of its suboxide in Si+3, and has a mean O/Si of 1.35 to 1.46 between its 10% and 90% points (the paper's first layer is SiO1.4). Its width is 0.28 nm (10-90%) or 0.47 nm (2-98%), narrower than the paper's 0.75 nm. Making it wider (slower reactions, or slower k3) raises its Si-Si bonds in step: at 0.86 nm (2-98%) it has 1.36 × 10^15. In this model, width and Si-Si count cannot be set separately to the paper's (100) pair. They can to the (111) pair: the “(111) set”, with k3 four times slower, gives 0.86 nm and 1.36 × 10^15 against the paper's 1.0 nm and 1.4 × 10^15. So the orientation effect would need an orientation-dependent last oxidation step; the template has no orientation term.

**Processing invariance is a consequence of one assumption.** With the rescaled parameters the width is the same at 600 and 850 °C, after 1 or 30 min, in 10% or pure O2 and after 30 min in N2 (all within 0.01 nm), which is the paper's central finding. ### What our language and ontology cannot yet say

- **An XPS observation statement.** The paper measures Si(2p) shifts, intensity ratios and linewidths, not a profile. An `OBSERVE XPS LINE Si2p TAKEOFF <deg> LAMBDA_OXIDE 2.5 nm LAMBDA_SI 2.3 nm` that turns a simulated profile into δ and R would let a model be scored on the measured Figures 5 to 7 rather than on the authors' 0.25 nm-layer fit.
- **Liquid and chemical-oxidant ambients.** Room-temperature water, boiling water, concentrated HNO3 and 30% H2O2 are half of the paper's oxidants. `AMBIENT liquid:H2O` or `liquid:HNO3` (with temperature) would let them be written; today boiling water is approximated as steam and the acids cannot be written at all.
- **An etch that removes a layer.** The 200 nm sacrificial oxide is grown and stripped in HF before every film. It had to be an EVENT because the language cannot take the oxide off again; a `STRIP oxide` or `ETCH TO 0 nm` would let the whole history be simulated, including what the first oxidation does to the silicon surface.
- **A group of samples with one pooled result.** The width is fitted to all (100) films together and stated to be the same for each. A result attached to a group of histories (`RESULT width 0.75 nm OVER SAMPLES 100_*`), rather than repeated on each, would say what was measured.
- **Ranges of temperature as an unknown of the sample group.** “100 to 700 °C” is a spread of samples, not an uncertainty about one; `VARY T_hold 100..700` searches it as if it were one unknown value. A way to say “one history per value in this range” would match what was done.
- **Adsorbed contamination.** A carbon layer of 0.2-0.6 nm on every surface (PDF p. 2) changes the XPS intensities; a sample field for an adsorbate layer would let an observation model account for it.

## What we would like Emily to check

1. The paper's width is the number of 0.25 nm non-stoichiometric layers in its fit. Is it fair to compare it with a model's 10-90% (or 2-98%) width of O/Si, or does a comparison need the XPS forward model (escape depth, linewidths)?
2. The 0.8 and 1.4 × 10^15 Si-Si bonds cm⁻²: would you count them as (4 - n)/2 per Si in each layer, as we did for the model, or do they include the bonds to the substrate's last plane?
3. Later high-resolution work (Himpsel et al. 1988) resolved Si+1, Si+2 and Si+3 at this interface. Should this page be paired with such a paper for the suboxide fractions, since Raider and Flitsch print none?
4. Room-temperature films in air and water (< 1.3 nm) are said to have the same transition region as 850 °C films. Is that plausible, given that native oxide grows by a different mechanism?
5. The thinnest film at 850 °C is about 1.1 nm by ellipsometry with n = 1.46. The paper's own Figure 11 says n is higher in thin films, so is 1.1 nm an overestimate, and by how much?
