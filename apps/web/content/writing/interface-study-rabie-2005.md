## The study and why we depend on it

**M. A. Rabie, Y. M. Haddara and J. Carette, “A kinetic model for the oxidation of silicon germanium alloys”, J. Appl. Phys. 98, 074904 (2005).**

The challenge's reference model for SiGe oxidation. Our SiGe growth program is this paper's model written in ISL with the constants it chose for one experiment (LeGoues et al.: 14% germanium, wet oxygen, 800 °C), and the predictor runs that program for every SiGe history. This page writes all four experiments the paper simulates as histories, so it shows both the reproduction of the one case and what happens when its constants are carried to the other three.

## How well can this study be reproduced?

**Low.** A modelling paper. The four experiments it simulates are other groups' and are described by three words each: germanium fraction, temperature, gas. Nothing about the alloy layer, the furnace, the steam pressure in “wet oxygen”, the loading or the time at which the germanium-rich layer was measured. Its rate constants and interdiffusivity are refitted for each experiment, so its agreement with the thickness curves is not a test of the model.

#### Timing the paper does not give

- Every oxidation time is read from a figure axis; the text gives none.
- Whether each point on a curve is a separate sample or one sample re-oxidized.
- Load temperature, push and the moment time zero is counted from, for all four experiments.
- The time at which LeGoues' germanium-rich layer (50 nm, up to 75%) was measured, and the time of the simulated profiles in Figures 7 and 8.
- Cooling and unloading: nothing is said.

### What the second reading changed

- The stored LeGoues recipe is one step, 180 min of `wet_O2` at 800 °C. `wet_O2` carries no partial pressures, so the inventory program runs it as pure steam (p_H2O = 1). Written as the 55% steam that the paper's own C* implies, the inventory's enriched layer falls from 91 to 69 nm and the alloy consumed from 65 to 49 nm; the Rabie program's thickness does not change because it does not read the gas.
- The germanium-rich layer (50 nm, up to 75%) has no time in the paper. Our dataset row puts it at 180 min, the last point of Figure 4, and scores it as a value (75%) although the paper says “up to”.
- The predictor runs the LeGoues constants (800 °C, wet oxygen, 14%) for any SiGe history and labels the result “direction only”, not “outside the tested scope”, at 700 °C in steam or 1000 °C in wet oxygen. On this page that gives a third of the measured oxide for Liu and a tenth for Zhang.
- Table II gives wet-oxygen diffusivity constants (D0 = 7.94e-7 cm²/s, E = 0.71 eV) but the text says the wet-oxygen values “were the same as those of H2O” (0.78 eV). Our program uses Table II.
- The program's interface condition is the silicon balance (F3 + F5) − (F3 + F4) yi, not the paper's Eq. 13 (F3 + F5 − F4); this is stated in the program.

The model itself, `experiments/rabie_sige/legoues_800C_14Ge.isl`, as it is written. Every equation the simulation uses is in this text; the runtime holds no physics.

```isl
# ==============================================================================
# ISL MODEL: WET OXIDATION OF A SiGe ALLOY WITH GERMANIUM PILE-UP
#
# The kinetic model of Rabie, Haddara and Carette, J. Appl. Phys. 98, 074904 (2005),
# written in ISL for one of the experiments they model: LeGoues et al., 800 C, wet
# oxygen, Si0.86Ge0.14. Every constant is taken from that paper's tables, where the
# reaction rates and the interdiffusivity were chosen by its authors for this experiment.
# Nothing is fitted here. Matching the thickness data is therefore a reproduction of
# a published model in this language, not an independent prediction.
#
# The silicon fraction y of the alloy is a FIELD on a grid that travels with the
# oxidation front. Seen from the front, alloy flows toward it at the front speed.
#
# One deliberate difference from the paper: its interface condition (Eq. 13) sets the
# diffusive silicon supply to F3 + F5 - F4. Balancing silicon atoms at the front gives
# (F3 + F5) - (F3 + F4) y_i, in the same units. This program uses the balanced form, so
# the silicon removed from the alloy is exactly the silicon oxidized.
# ==============================================================================
SAMPLE Alloy_LeGoues_800C {
    FAMILY: SiGe_oxide
    COMPOSITION: Si0.86Ge0.14
}
# Depth below the oxidation front, on a grid that travels with it.
GRID z { UNIT: cm; FROM: 0; TO: 1.0e-5; CELLS: 100 }
FIELD y { UNIT: 1; GRID: z; INITIAL: y_bulk; MIN: 0; MAX: 1 }
STATE L_ox { UNIT: cm; INITIAL: L_0; MIN: 0; MAX: 1.0e-3 }
# Thickness-equivalent of GeO2 in the oxide: the oxide's GeO2 fraction is G_ox / L_ox.
STATE G_ox { UNIT: cm; INITIAL: 0; MIN: 0; MAX: 1.0e-3 }
# Silicon and germanium atoms taken from the alloy, per unit area, for the balance check.
STATE N_Si_out { UNIT: cm^-2; INITIAL: 0; MIN: 0; MAX: 1.0e20 }
CONTROL T { UNIT: K }
# ---- reaction rates and interdiffusivity chosen by Rabie et al. for this experiment ----
PARAMETER k1 { VALUE: 3.8333e-6; UNIT: cm s^-1; STATUS: sourced; SOURCE: Rabie et al. 2005 Table III, 2300 nm/min, Ge oxidation, agent-read }
PARAMETER k2 { VALUE: -1.6667e-7; UNIT: cm s^-1; STATUS: sourced; SOURCE: Rabie et al. 2005 Table III, -100 nm/min, agent-read }
PARAMETER k3 { VALUE: 2.5e-8; UNIT: cm s^-1; STATUS: sourced; SOURCE: Rabie et al. 2005 Table III, 15 nm/min, replacement reaction, agent-read }
PARAMETER D_SiGe { VALUE: 4.9167e-16; UNIT: cm^2 s^-1; STATUS: sourced; SOURCE: Rabie et al. 2005 Table V, 2.95 nm^2/min, agent-read }
# ---- oxidant in the oxide ---------------------------------------------------------------
PARAMETER C_Si_star { VALUE: 1.647e19; UNIT: cm^-3; STATUS: sourced; SOURCE: Rabie et al. 2005 Table II, wet O2, agent-read }
PARAMETER C_Ge_star { VALUE: 2.471e19; UNIT: cm^-3; STATUS: sourced; SOURCE: Rabie et al. 2005 Table IV, wet O2, agent-read }
PARAMETER D0_ox { VALUE: 7.94e-7; UNIT: cm^2 s^-1; STATUS: sourced; SOURCE: Rabie et al. 2005 Table II, wet O2, agent-read }
PARAMETER E_ox { VALUE: 0.71; UNIT: eV; STATUS: sourced; SOURCE: Rabie et al. 2005 Table II, wet O2, agent-read }
PARAMETER h_gas { VALUE: 2.7778; UNIT: cm s^-1; STATUS: sourced; SOURCE: Rabie et al. 2005, 1e8 um/h stated below Eq. 7b, agent-read }
PARAMETER N1_Si { VALUE: 4.4e22; UNIT: cm^-3; STATUS: sourced; SOURCE: Rabie et al. 2005 Table I, wet oxidation, agent-read }
PARAMETER N1_Ge { VALUE: 4.87e22; UNIT: cm^-3; STATUS: sourced; SOURCE: Rabie et al. 2005 Table I, wet oxidation, agent-read }
PARAMETER N_SiO2 { VALUE: 2.2e22; UNIT: cm^-3; STATUS: sourced; SOURCE: Rabie et al. 2005 Section IV, agent-read }
PARAMETER N_GeO2 { VALUE: 2.436e22; UNIT: cm^-3; STATUS: sourced; SOURCE: Rabie et al. 2005 Section IV, agent-read }
# ---- assumptions ------------------------------------------------------------------------
# The alloy is given silicon's atomic density; the paper uses C_Si without stating its value.
PARAMETER C_at { VALUE: 5.0e22; UNIT: cm^-3; STATUS: hypothesis }
# "A layer of oxide of very small thickness" (paper); 1 nm assumed.
PARAMETER L_0 { VALUE: 1.0e-7; UNIT: cm; STATUS: hypothesis }
PARAMETER y_bulk { VALUE: 0.86; UNIT: 1; STATUS: sourced; SOURCE: Rabie et al. 2005, 14% Ge alloy of LeGoues et al., agent-read }
PARAMETER k_B { VALUE: 8.617333262e-5; UNIT: eV K^-1; STATUS: constant }
# ---- the paper's algebra, each expression written once ------------------------------------
QUANTITY theta { UNIT: 1; EQUATION: theta = G_ox / L_ox }
QUANTITY y_i { UNIT: 1; EQUATION: y_i = left(y) }
QUANTITY k_eff { UNIT: cm s^-1; EQUATION: k_eff = k1 + k2 * y_i }
QUANTITY C_star { UNIT: cm^-3; EQUATION: C_star = theta * C_Ge_star + (1 - theta) * C_Si_star }
QUANTITY D_ox { UNIT: cm^2 s^-1; EQUATION: D_ox = D0_ox * exp(-E_ox / (k_B * T)) }
QUANTITY N1 { UNIT: cm^-3; EQUATION: N1 = 1 / (theta / N1_Ge + (1 - theta) / N1_Si) }
QUANTITY N_ox { UNIT: cm^-3; EQUATION: N_ox = 1 / (theta / N_GeO2 + (1 - theta) / N_SiO2) }
QUANTITY C_i { UNIT: cm^-3; EQUATION: C_i = C_star / (1 + k_eff / h_gas + k_eff * L_ox / D_ox) }
QUANTITY F3 { UNIT: cm^-2 s^-1; EQUATION: F3 = (k1 + k2) * y_i * C_i }
QUANTITY F4 { UNIT: cm^-2 s^-1; EQUATION: F4 = k1 * (1 - y_i) * C_i }
QUANTITY F5 { UNIT: cm^-2 s^-1; EQUATION: F5 = k3 * theta * N_ox * y_i }
# F3, F4 and F5 count oxidant molecules. Each oxide unit takes N1 / N_SiO2 of them (two for water),
# so atoms leave the alloy at N_SiO2 / N1 times those fluxes. Front speed is the paper's Eq. 18.
QUANTITY atoms_per_oxidant { UNIT: 1; EQUATION: atoms_per_oxidant = N_SiO2 / N1 }
QUANTITY v_front { UNIT: cm s^-1; EQUATION: v_front = atoms_per_oxidant * (F3 + F4) / C_at }
QUANTITY Si_removal { UNIT: cm^-2 s^-1; EQUATION: Si_removal = atoms_per_oxidant * (F3 + F5) }
CONTROL_TRAJECTORY Oxidation_800C {
    RUN WetOxidation DURATION 10800.0 TEMP 800.0->800.0 AMBIENT wet_O2
}
# Paper Eq. 10 and Eq. 19.
OPERATOR F_OxideGrowth : OxideGrowth {
    EQUATION: d(L_ox)/dt = (F3 + F4) / N1
    EQUATION: d(G_ox)/dt = (F4 - F5) / N1
}
# Paper Eq. 12 on the travelling grid, with the balanced interface condition. Silicon leaves
# the alloy through the front at the rate it is oxidized; far from the front the alloy is undisturbed.
OPERATOR F_AlloyInterdiffusion : Transport {
    FLUX: J(y) = -D_SiGe * grad(y) + upwind(y, -v_front)
    BOUNDARY: y AT left FLUX = -Si_removal / C_at
    BOUNDARY: y AT right VALUE = y_bulk
    EQUATION: d(N_Si_out)/dt = Si_removal
}
OBSERVATION_MODEL Obs_Oxide_Thickness { TARGET: Thickness; UNIT: cm; EQUATION: Thickness = L_ox }
OBSERVATION_MODEL Obs_Interface_Si { TARGET: Si_at_front; UNIT: 1; EQUATION: Si_at_front = left(y) }
OBSERVATION_MODEL Obs_Si_In_Grid { TARGET: Si_in_grid; UNIT: cm; EQUATION: Si_in_grid = integral(y) }
OBSERVATION_MODEL Obs_Si_Oxidized { TARGET: Si_oxidized; UNIT: cm^-2; EQUATION: Si_oxidized = N_Si_out }
OBSERVATION_MODEL Obs_GeO2_Fraction { TARGET: GeO2_fraction; UNIT: 1; EQUATION: GeO2_fraction = G_ox / L_ox }
EVALUATION_CONTRACT Contract_LeGoues_800C {
    FROZEN: true
    DATASET: data/derived/rabie_2005_legoues_thickness.csv
    DATASET_DIGEST: sha256:DATASET_SHA256
    SPLIT: reproduce
    TARGET: Thickness @ 600 = 2.0e-6 +/- 6.0e-7 abs
    TARGET: Thickness @ 2700 = 5.2e-6 +/- 6.0e-7 abs
    TARGET: Thickness @ 7200 = 9.6e-6 +/- 9.6e-7 abs
    TARGET: Thickness @ 10800 = 1.36e-5 +/- 1.36e-6 abs
}
```

One timing unknown was searched, the push into the furnace before the figure's clock starts (5 s to 20 min, in the oxidation gas, from 200 °C below the oxidation temperature), chosen on the LeGoues case alone; the Liu and Zhang curves are the test. The steam fraction of “wet oxygen” is a choice of material input, tried as variants (30%, 90%, pure steam) against the 55% the paper's own C* implies.

**The push does not fix the LeGoues curve's shape.** Our program, with the paper's constants, gives 9.4, 38.4, 98.8 and 145 nm at 10, 45, 120 and 180 min with no push, against 20, 52, 96 and 136 nm read from Figure 4. The measured curve starts about 10 nm higher and rises more slowly; the program's is nearly a straight line through the origin, as the paper's own line in Figure 4 is. A longer push lifts every point by the same few nanometres: at 193 s (the search's choice, 2 of 6 LeGoues numbers within tolerance, median error 27% against 28% at 60 s) the 10 min point is 12.0 nm and the 180 min point 147.5 nm; at 8 min the 10 min point reaches 16 nm and the 180 min point leaves its tolerance (151 nm). No push puts both ends within 10%. What the early points want is a starting oxide of about 10 nm or a fast initial regime, and the starting oxide is a hypothesis inside the program (1 nm), not something the history can state.

**The steam fraction moves only the inventory program.** The Rabie program does not read the gas, so its thickness, GeO2 fraction and the germanium at the interface are the same at every fraction. The inventory's germanium-rich layer extent is 47 nm at 30% steam, 66 nm at 55%, 86.5 nm at 90% and 91.6 nm as pure steam, against the 50 nm printed; 30% steam brings it within tolerance (4 of 26 numbers instead of 3). That is not evidence for 30% steam: the inventory's wet growth constants were fitted on this same experiment with wet oxygen run as pure steam, so a lower fraction simply grows less oxide in that program, and the layer extent follows the oxide.

**The other three experiments are out of reach of any unknown in the history.** With the LeGoues constants, the Liu and Zhang curves are 56 to 96% low at every point (1 of 20 test numbers within tolerance, median error 76% before and 75% after alignment); the one within tolerance is the GeO2 fraction of Liu's 36% alloy (31.5% against 35% by RBS). What alignment cannot fix. The LeGoues germanium at the interface (75% measured, 44% from the enrichment relation the predictor reports, 51.5% from the Rabie program, 45% from the paper's own model) does not depend on any unknown we can write. The Liu and Zhang thicknesses need the paper's per-experiment constants, which our program does not carry; the predictor applies the 800 °C wet-oxygen constants to 700 °C steam and 1000 °C wet oxygen and labels the result “direction only” instead of refusing it or marking it outside its scope.

How to read the aligned numbers: the push was chosen on the LeGoues case, whose constants are the paper's fit to the same curve, so the LeGoues rows are not a test and are not shown in the aligned table. The Liu and Zhang rows are a test of transfer, which the program fails.

### What our language and ontology cannot yet say

- **Wet oxygen by its steam pressure, or by its source.** `wet_O2` carries no partial pressures. A history should be able to say `mix:H2O=x,O2=1-x`, as here, or name the source (`BUBBLER 95 C`, `PYROGENIC H2:O2 1.8`) from which the pressure follows. Here the fraction moves the layer extent from 47 to 92 nm.
- **Constants that belong to a condition, and a refusal outside it.** The program's k1, k2, k3 and DSiGe are the paper's for 800 °C, wet oxygen, 14%. A parameter should carry the conditions it was chosen for (`VALID T 800; AMBIENT wet; GE 0.14`), so the predictor labels or refuses a 700 °C steam history instead of answering it.
- **Programs that read the gas.** The Rabie program ignores the ambient entirely: a push or a cooling in nitrogen would grow oxide in it, and dry oxidations (David 2015) are run with wet-oxygen constants.
- **A starting oxide on the sample.** The model's initial oxide (“very small thickness Lox”) is a 1 nm hypothesis inside the program. The early LeGoues points ask for about 10 nm; a `STARTING_OXIDE` field would make that an unknown the alignment can search.
- **Report every observable a program computes.** The Rabie program computes the germanium at the front (51.5% here) and the predictor drops it, reporting the enrichment relation's 44% under the same name. Two programs answering one target should both be reported, each with its name.
- **A measurement with no time.** “A 50-nm-thick Ge-rich layer was obtained with up to 75% Ge” has no oxidation time. A result should be able to say `AT unknown` (or a range of times) and be compared over that range, not at the time we chose.
- **An upper value as data.** “Up to 75%” is scored as 75 ± 10%. A result should carry `≤`, `≥` or `about`, so that a program giving 60% is not counted as wrong by the same rule as one giving 44%.
- **A finite alloy layer.** The source experiments are epilayers of unstated thickness; Table VI consumes up to 425 nm of alloy. The sample cannot say how thick the alloy is or what lies under it.
